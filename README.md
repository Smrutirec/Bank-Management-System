# Student Task Manager
## Project Description
Student Task Manager is a web application
developed using HTML, CSS and JavaScript.
It helps students organize their academic activities and manage daily tasks.
## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Features
- Add new tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- Filter tasks
- Local Storage


## Installation
1. Clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
